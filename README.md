# Blue Giraffe Next.js Website

Run locally with `npm install` then `npm run dev` and open `http://localhost:3000`.

Add three hero images as `public/images/hero-1.png`, `hero-2.png` and `hero-3.png`. The hero slider changes every five seconds and also has arrows and indicator dots.

Keep large videos out of GitHub. Store `hero.mp4` and `md.mp4` in a video host or add them through a storage/CDN service before production deployment.
